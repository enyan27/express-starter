# React Vite + Express Template

## Initial Setup

#### Backend (MongoDB)

```bash
npm i dotenv express helmet mongodb mongoose morgan pino pino-pretty
npm i -D nodemon
```

#### Backend (PostgreSQL)

```bash
npm i dotenv drizzle-orm express helmet morgan pg pino pino-pretty
npm i -D drizzle-kit nodemon
```

#### Frontend

```bash
npm i axios zustand
npm i -D @tailwindcss/vite tailwindcss
```

## Build & Run

```bash
npm run build
npm run start
```

## Format Code

```bash
npm run prettier
```
